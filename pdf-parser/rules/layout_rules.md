# 版面判定口径

## 栏数

- **单页判定**（不跨页平均）：统计"行内存在 ≥3 空格间隙、且左右两段都 >8 字符"的行占比
  - ≥ 50% 且该页非空行 ≥ 6 → 判双栏
  - 否则单栏
- 三栏及以上：不自动重排，用 `--columns 1` 保序输出并在 `issues` 标注"未自动重排"
- 表格页常被误判为双栏：表格单元格通常较短，靠 ">8 字符" 规则可减少误判；仍误判时用 `--columns 1`

## 页眉页脚

- 同一行文本在 ≥2 页出现、长度 ≤90 字符、且位于页首/页尾 2 行内 → 剔除
- 只按"页首/页尾位置"剔除，避免误删正文中重复出现的句子
- 页脚中的纯页码（1~3 位数字）直接丢弃

## 阅读顺序

- 双栏页：先左栏全部块，再右栏全部块（同一页内）
- 跨页续接：不做自动拼接，保留页边界，锚点连续
- 标题行（≤60 字符且匹配章节正则）单独成块，避免与正文粘连

## 表格

- 判定：连续 ≥3 行、每行 ≥2 列（两空格以上分隔）、各列起始位置差 ≤3 字符
- 列数不一致 → "可能含合并单元格"，不拍平成错误数据
- 相邻页各有一表 → "可能为续表"，需人工确认是否合并
- 表头取第一条对齐行；跨行表头不自动推断

## 锚点

- 块锚点 `bNNNN` 按**输出顺序**连续编号（已重排），不是原始版面坐标
- 每块保留 `page` 与 `col`，可回到原页核对
