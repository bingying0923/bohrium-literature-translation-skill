# 饮用水中铅离子的便携式检测

饮用水中铅污染仍然是许多地区的公共卫生问题 [1]。便携式光学传感器可能支持缺乏实验室条件的现场筛查 [2]，比色法已被用于水质快检 [3]。近期工作把该方法推进到现场验证 [2,4]。
