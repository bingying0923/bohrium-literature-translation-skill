# 引用管理判定口径

## 引用标记

| 形式 | 示例 | 解析为 |
|---|---|---|
| 单条 | `[3]` | 3 |
| 区间 | `[4-5]`、`[4–5]` | 4,5 |
| 并列 | `[1,3]`、`[1, 3]` | 1,3 |
| 著者-年 | `(Smith et al., 2020)` | author=Smith, year=2020 |

## 编号

- **顺序原则**：按正文首次出现顺序编号（顺序编码制）
- **连续性**：1..N，不允许空号；未被引用的条目排在最后并保留告警
- **区间渲染**：连续 3 个及以上才合并为 `a-c`；2 个用逗号

## 去重

判定键优先级：

1. DOI 相同 → 同一文献
2. 题名归一（去标点/大小写/空白）相同 → 同一文献
3. 作者+年份+题名首词 相同 → 疑似重复，标 warning（不自动合并）

合并时保留**信息更全**的那条（字段非空数量多者），其余记入 `changes.merged_duplicates`。

## 字段完整性

必须字段：`authors`、`year`、`title`。
缺任一 → `incomplete_entries`，视为阻断（不猜、不占位）。

## 样式

- `numeric`：正文 `[n]`，列表 `[n]` 开头
- `author-year`：正文 `(Author, Year)`，列表按作者字母序
- 混用 → 记 `style_mixed`，先统一再重排

## 可回溯

每条保留 `old_index`，`citation_changes.csv` 给出 旧→新 映射，
便于作者核对"我原来引的第 3 条现在变成第几条"。
