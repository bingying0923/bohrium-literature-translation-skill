# 笔记写法与锚点规范

## 一条笔记 = 一句判断 + 一个锚点

格式：

```
[类型] 这句话说了什么（保留数字与限定词）。 （p012, 第 3 页）
```

`类型` 取值：`question` / `method` / `data` / `result` / `claim` / `limitation` / `novelty`

## 允许

- 压缩长句，但**保留**：数字、单位、比较方向（高于/低于）、限定词（可能/提示/部分）
- 章节承接：`Methods 的 0.8 µg/L 检出限在 Results 中被复现`
- 术语首次出现给全称，之后用缩写

## 禁止

- 把 Discussion 的推测写成 Results 的事实
- 新增原文没有的因果（because/therefore/导致）
- 改数字、改样本量、改单位
- 一条笔记引用多个不连续段落（应拆成多条）

## 覆盖要求

除 References / Acknowledgments 外，**每个有内容的章节至少 1 条笔记**；
Methods 与 Results 建议各 2~3 条（方法参数与关键结果最常被引用）。
