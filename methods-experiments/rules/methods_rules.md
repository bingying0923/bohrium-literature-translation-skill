# 方法与实验章节规则

## 结构（顺序固定）

1. 材料与数据：数据集名、版本、规模、预处理、划分比例与随机方式
2. 实验设置：硬件、软件版本、运行环境、随机种子、重复次数
3. 方法步骤：有序，每步写清 输入 / 操作 / 输出 / 判断条件
4. 对照与评价：基线对象及版本、是否同预算、指标与统计方式
5. 复现清单：代码版本、环境、命令、数据获取路径
6. 限制条件：指向具体失效场景（如"潮湿环境下未验证"），不写套话

## 参数表

| 列 | 要求 |
|---|---|
| 名称 | 与配置文件/日志一致 |
| 取值 | 与日志一致；冲突以日志为准 |
| 单位 | 必填；无量纲写 `-` |
| 作用对象 | 该参数作用于哪一步 |
| 来源 | `config` / `log` / `author`；缺来源标 `unverified` |

## 禁止

- 为句子顺滑补数值
- 把训练/验证/测试条件写在同一个句子里导致串台
- 声称"可复现"但缺 seed、版本或命令
- 用"优于基线"掩盖不同预算的对比

## 缺口写法

- 未记录：`not_recorded`
- 无法核对：`unverified` + 说明
- 版本含混：`version=unknown` + 说明对复现的影响
