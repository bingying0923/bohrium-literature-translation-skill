# Bohrium 校园挑战赛 · 北京化工大学分站赛 — 参赛作品集

本仓库收录参加 **Bohrium Science Space 校园挑战赛（北京化工大学分站赛，第一期）** 的 5 个 Skill 作品。
每个作品都是可被 Agent 直接调用的技能包：`SKILL.md`（含 YAML 元信息）+ 脚本 + 规则表 + 示例。

| 赛题 | 目录 | 核心能力 |
|---|---|---|
| 文献翻译 | 仓库根目录（`SKILL.md`） | 术语锁定的双语段落对照：分段编号、术语全篇锁定、数字/单位/引用/公式/否定六项核验 |
| 学术语言润色 | [`academic-polish/`](academic-polish/) | 最小编辑润色：限定强度守恒、数字与引用不动、逐句修改记录（原文/改文/类型/理由） |
| 文献总结与结构化笔记 | [`paper-notes/`](paper-notes/) | 章节对齐笔记 + 论文卡片（7 字段必带锚点）+ 覆盖度与数字溯源核查 |
| 文献文档解析 | [`pdf-parser/`](pdf-parser/) | 逐页双栏重排、页眉页脚剔除、表格转 Markdown、章节树与题注/公式定位 |
| 参考文献与引文管理 | [`citation-manager/`](citation-manager/) | 引用解析、七项一致性核查、按首次出现重排编号、去重合并、旧→新映射 |

## 共同设计原则

1. **可核验**：每个输出都带锚点（段落/页/块号），能点回原文
2. **诚实**：缺失写 `not_reported` / `partial` 并列出 `todo`，不编造数据与文献
3. **守恒**：改写/翻译/重排时不改变数字、单位、引用编号、图表指向与主张强度
4. **可复用**：规则表（`rules/*.md`）与脚本解耦，换学科只需换术语表与字段字典

## 本地运行

```bash
python3 scripts/<script>.py --help
```

依赖：Python 3.8+ 标准库，无第三方包。

## 许可

仅用于赛事提交与学术交流。
