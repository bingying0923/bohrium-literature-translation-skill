# 引言与相关工作写作规则

## 背景段

- 三句话结构：领域脉络 → 具体问题 → 技术约束
- 每句要么带引用，要么显式标 `[author-claim]`
- **禁止**：
  - "近年来，X 受到广泛关注"（无信息量）
  - "具有重要意义"（不可核对）
  - "众所周知"（无出处）

## 相关工作

- 按**维度**分组，不按时间罗列。可用维度：
  1. 问题设定（检测限优先 / 通量优先 / 现场部署优先）
  2. 方法路线（光学 / 电化学 / 质谱）
  3. 数据与评价方式（实验室标定 / 现场验证 / 跨批次稳定性）
- 每组写：代表工作 + **共同限制**（这组没解决什么）
- 每组 ≥2 篇；同组内做取舍比较，不逐篇摘要

## 研究空白

- 必须由"各组的共同限制"推出，并引用被限制的文献
- 句式：`上述工作在 A 方面有效，但在 B 条件下受限于 C [ref]`
- 不写"尚未见报道"除非确实检索过（注明检索日期）

## 贡献

- 3~4 条，每条一个动词开头：提出/构建/验证/证明（谨慎使用）
- 每条必须带证据：`Fig. N` / `Table N` / 具体数值
- 不扩大适用范围：`在三个城市的水样上` 不能写成 `在各种水体中`

## 引用

- 统一一种样式（`[n]` 或 `(Author, Year)`），不混用
- 每条引用都要在文献清单中存在；清单中未被引用的条目要么补引要么删除
- 引用位置贴在**需要来源支撑的论断**后面，不放段落末尾凑数
